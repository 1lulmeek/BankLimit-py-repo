# BankLimit

BankLimit is a Python command-line budgeting application designed to help users create and manage personalized spending categories and spending limits.

## Features

* Create custom budget categories
* Add subcategories with individual spending limits
* View and remove existing categories
* Modify category spending limits
* Calculate monthly income from annual income
* Generate budget allocations using the 50/30/20 budgeting rule
* Validate user input and handle invalid values

## Technologies

* Python
* Object-Oriented Programming (OOP)
* Dictionaries
* Exception Handling
* Command-Line Interface (CLI)

## Running the Program

1. Download or clone the repository.
2. Make sure Python is installed.
3. Open a terminal in the project directory.
4. Run:

`python banklimit.py`

## Project Status

BankLimit is currently under development. Additional budgeting and transaction-management features are planned.
